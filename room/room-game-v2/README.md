# Aura_buttle_Feelings

room-game-v2

Активный интерфейс сайта и игры находится в этой папке `room/room-game-v2`.
Корневой `server.py` раздаёт страницу, стили, скрипты и изображения именно отсюда.
Для оценки эмоций сервер использует Ollama-модель `qwen3-vl:4b-instruct`;
`start.sh` проверяет и загружает её перед запуском игры.

## Озвучка
- По умолчанию используется русский голос браузера: он запускается прямо по действию пользователя и обычно надёжнее на телефонах. Если браузерный синтез недоступен, приложение пробует Piper Irina (`ru_RU-irina-medium`).
- Чтобы сделать Piper основным голосом, задайте `TTS_MODE: "piper"` в `js/config.js`. В браузерном WASM-режиме модель (~63 МБ) загружается один раз и кешируется; на слабых устройствах синтез может снизить частоту видеокадров.
- Свой Piper-сервер: задайте `TTS_MODE: "piper"`, запустите `python -m piper.http_server -m ru_RU-irina-medium --port 5000`, затем в `js/config.js` → `PIPER.SERVER_URL: "http://localhost:5000"`
  (если сайт и сервер на разных адресах, нужен CORS или обратный прокси).
- Если Piper недоступен — автоматически используется голос браузера.
- Новые фразы из комнаты автоматически озвучиваются по-русски; кнопка «Озвучка» в игровом экране включает и выключает голос.


## Добавленные возможности
- Одно общее чувство на всю комнату; сервер меняет его одновременно для всех участников.
- Таблица лидеров по сумме очков за всё время (в mock-режиме хранится в `localStorage`).
- После раунда отображается место победителя в общем рейтинге; при объявлении победителя звучит отдельная мелодия.
- Переключение светлой/тёмной темы в главном меню с сохранением выбора.
- Вход в комнату выполняется через одну форму с кодом и именем; первый вошедший создаёт комнату указанного кода.
- Играть можно одному или с любым количеством участников. Таймер и оценка кадров начинаются только после нажатия «Начать».
- Раунд длится 30 секунд: в нём три общие эмоции, каждая показывается 10 секунд. Оценки 0–100 усредняются отдельно для каждого игрока.
- Камера запрашивает поток до 25 кадров/с; оптимизированные JPEG-кадры до 480×360 передаются по WebSocket бинарными сообщениями.

## Контракты реального API
При `USE_MOCK: false` сервер должен реализовать следующие дополнительные маршруты:
- `GET /rooms/:code/feeling` — возвращает одно общее чувство комнаты, например `{ "feeling": "Радость" }` (клиент также поддерживает прежнюю карту `playerId -> feeling`).
- `POST /admin/rooms/open` с `{ "accessCode": "000000" }` — сервер проверяет секрет и открывает/возвращает отдельную админскую комнату.
- `POST /admin/rooms/:code/test-players` — добавляет тестового игрока; сервер обязан разрешать это только для админской комнаты и авторизованной админской сессии.
- `GET /api/leaderboard` — массив `{ "nick": "...", "score": 123 }`, отсортированный по сумме очков за всё время. Сервер добавляет средний балл каждого игрока за раунд в постоянный рейтинг при завершении комнаты.
- `POST /rooms/:code/finish` — после сохранения результатов возвращает `{ "ok": true, "rank": 1, "totalScore": 123 }` для победителя.

**Важно:** проверка `000000` в браузере — только интерфейсный барьер. Для реального сервера код и права администратора обязательно нужно проверять на сервере; не полагайтесь на клиентскую проверку.


## Дополнительные изменения меню
- Виджеты времени и лучшего игрока имеют одинаковую высоту и ширину.
- Переключение светлой/тёмной темы сопровождается плавным переходом цветов.
- Нажатие на слово «семпай» показывает приложенную картинку в случайном месте экрана; через несколько секунд она плавно гаснет и исчезает.
